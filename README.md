# The Business Architect’s Edge — companion resources

Companion worksheets and worked technical fixtures for John Briggs's *The Business Architect’s Edge: Connecting AI, Engineering, and Business Outcomes*.

Harbor Learning and all records, people, costs, metrics, and systems in these files are fictional teaching examples. These files are not production configurations or evidence of results at any real institution.

| Book chapter | Resource | Use |
|---|---|---|
| API design | [OpenAPI example](examples/ch09-r7-api.yaml) | Inspect the proposed contract, authority limits, error model, and idempotency key |
| Enterprise integration | [Mapping worksheet](examples/ch10-r7-mapping.csv) | Identify source, consumer view, and forbidden translation |
| Enterprise integration | [Synthetic reconciliation data](data/fig-ch10-data.json) | Reproduce the 96 + 1 + 3 comparison |
| Microservices | [Boundary worksheet](examples/ch11-boundary-decision.csv) | Decide who owns each fact and effect |
| Service orchestration | [Recovery decision card](examples/ch12-recovery-card.csv) | Work through ambiguous dispatch and replay |
| Event-driven architecture | [Event fixture](examples/ch13-r7-events.json) and [consumer decisions](examples/ch13-consumer-decisions.csv) | Test event meaning, order, duplicates, and unknown versions |
| Recovery | [Recovery ledger](examples/ch14-recovery-ledger.csv) | Rehearse view repair without sending learner-facing effects |

The book gives the context, questions, and limits for each exercise. Work from the chapter before copying a fixture.
