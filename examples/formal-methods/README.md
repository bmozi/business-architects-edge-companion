# Formal-methods practice assets

Use the worked lessons and attempt the paper exercises first. All Harbor states are fictional proposals.

- [BPMN handoff](bpmn/README.md): descriptive native BPMN 2.0.2 XML and a broken boundary example.
- [ArchiMate 4 view](archimate/README.md): original editable teaching JSON, selected relationship trace and broken meaning example. This is not an official interchange schema or vendor project.

The companion includes SVGs and standalone offline checkers under `scripts/`. Check results cover the documented teaching subset, not complete standards conformance, runtime execution, policy authority or observed business outcomes. Standards PDFs are not distributed.
