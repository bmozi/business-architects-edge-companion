# Authority Card: fictional worked example

From reader Chapter 6. Separate a proposal from a currently permitted action and preserve human ownership. These are proposed or illustrative Harbor records, not actual agreements or outcomes.

| Field | Harbor candidate decision |
|---|---|
| Outcome hypothesis | Better prepared internal handoffs reduce avoidable staff rework without misrepresenting learner status |
| Entry condition | Authenticated, authorized staff member explicitly opens a task for one accessible learner |
| Permitted evidence | Current approved R7 guidance and the minimum case-summary fields authorized for that task; no unrelated learner records or general web browsing |
| AI contribution | Select permitted evidence, ask a clarification, propose a concise support-case draft and an allowed queue |
| Human decision | Staff verify content, disclosure, queue and purpose; an authorized approver accepts the exact submission |
| Execution authority | Dedicated service creates at most one internal case for the approved operation; no eligibility decision, learner-record update, outbound message or attachment upload |
| Approval binding | Actor, task, workspace, learner, operation ID, exact normalized content, queue, source/state versions, policy version and expiry |
| Resource envelope | At most four model calls, one concurrent model call, sixty seconds for planning, and 100 synthetic cost units reserved through a trusted ledger |
| Stop conditions | User stop, deadline, exhausted envelope, missing authorization, changed evidence, invalid approval, or uncertain external effect |
| Evidence record | Configuration version, authorized context references, proposal/approval versions, action status, tool receipt and incident correlation; protect content and limit retention |
| Operation and recovery | Platform on-call controls execution; admissions operations owns case correctness and reconciliation; security/privacy handles suspected disclosure; policy owner retains eligibility interpretation |
| Fallback | Staff use the existing support process; no extra AI authority is granted to finish a failed task |
