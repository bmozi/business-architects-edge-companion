# Value Stage Map: fictional worked example

From reader Chapter 26. Define a stakeholder value stream with proposed stage entry and exit conditions. These are proposed or illustrative teaching records, not actual agreements or outcomes.

| Stage | Enter when | Value and exit condition |
|---|---|---|
| **S1 Understand requirements** | The learner needs to address an applicable requirement | Current approved meaning and a usable submission/help route are available; unanswered questions retain an owner |
| **S2 Submit information** | The learner has information to offer against the requirement | Receipt is recorded and accurately explained, or a failed submission has an owned recovery path; no review decision is implied |
| **S3 Receive authorized review** | Submitted evidence is available to an authorized reviewer | A disposition is recorded under the applicable rule, or a request for more information or unresolved decision is explicitly owned |
| **S4 Know the next action** | A disposition or owned unresolved state exists | The learner can understand the authorized next step and reach help if that explanation is unusable |
